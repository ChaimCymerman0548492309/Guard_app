# הדגמת התראה על טלפון אמיתי (VPN)

מדריך קצר לבדיקה **חוקית ובטוחה** — בלי malware. Guardian מזהה דפוסים חשודים (מעקב, דומיינים חדשים, העלאות גדולות) לפי מטא-נתונים מה-VPN.

## לפני שמתחילים

1. APK preview / dev build עם **ניטור VPN פעיל** (סמל VPN בראש המסך).
2. **התראות** מופעלות בהגדרות האפליקציה ובהגדרות Android.
3. שפה **עברית** בהגדרות → Guardian (או שפת מכשיר עברית) — ההסברים וההתראות יופיעו בעברית.

## תרחיש 1: דומיין מעקב (הכי קל)

1. הפעל **התחל ניטור** במסך הגדרת ניטור.
2. פתח **Chrome** (או דפדפן אחר).
3. גלוש לאתר שטוען פרסומות/מעקב, למשל:
   - עמוד חדשות גדול עם באנרים
   - או חיפוש ב-Google ופתיחת כמה תוצאות
4. חזור ל-Guardian → **אפליקציות** → בחר **Chrome**.
5. חפש סטטוס **לא רגיל** / **חשוד** וכלל **דומיין מעקב מוכר**.

**למה זה עובד:** Chrome מתחבר לדומיינים כמו `doubleclick.net`, `google-analytics.com` וכו' — הם ברשימת המעקב של Guardian.

**התראה:** אם רמת הסיכון **חשוד** (למשל כמה כללים יחד), תקבל push: **«התראה: Chrome»** עם הסבר בעברית.

## תרחיש 2: דומיין חדש + פעילות רשת

1. VPN פעיל.
2. ב-Chrome, בקר באתר שלא ביקרת בו הרבה מהטלפון (דומיין חדש עבור Chrome).
3. רענן כמה פעמים או פתח כמה תת-דפים.
4. ב-Guardian → פרטי Chrome → כלל **קשר לדומיין חדש**.

## תרחיש 3: העלאה גדולה (חריג)

1. VPN פעיל.
2. העלה קובץ גדול (~300MB+) דרך דפדפן או אפליקציית ענן (Drive, WeTransfer וכו').
3. Guardian מסכם **נפח העלאה** לפי אפליקציה — כלל **העלאה גדולה**.

> סף ברירת מחדל: כ-300MB בחלון הניטור הנוכחי (ראה `LARGE_UPLOAD_BYTES` ב-shared).

## תרחיש 4: הדגמה מלאה בלי VPN (מצב סימולטור)

רק ב-build עם `EXPO_PUBLIC_DEV_SIMULATOR=true`:

- במסך הבית → **הפעל הדגמת ניקוי תמונות** — מייצר סценario **חשוד** עם התראה מיידית.

ב-APK preview רגיל (VPN אמיתי) — השתמש בתרחישים 1–3.

## מה **לא** לעשות

- לא להתקין APK זדוני או «כלי פריצה» — לא נדרש ומסוכן.
- לא לצפות ש-Guardian יקרא תוכן HTTPS — רק דומיינים וגדלים.

## פתרון בעיות

| בעיה         | מה לבדוק                                                                       |
| ------------ | ------------------------------------------------------------------------------ |
| אין התראה    | רק **חשוד** מקבל push מיידי; **לא רגיל** לפעמים בלי sound. בדוק הרשאות התראות. |
| אין אירועים  | VPN מחובר? DNS over HTTPS בדפדפן מקשה על זיהוי דומיין — נסה אתר אחר.           |
| טקסט באנגלית | הגדרות → שפה → **עברית**, או משוך עדכון אחרון מה-repo.                         |
