# Feature Graphic (Play Store)

## Specifications

| Property | Value |
| -------- | ----- |
| Dimensions | **1024 × 500 px** |
| Format | PNG or JPEG (no alpha) |
| Max file size | 1 MB |

## Design guidance

- Background: Guardian brand blue `#1e3a5f`
- App name: **Guardian** in white, bold
- Tagline (EN): "Your privacy, protected"
- Tagline (HE): "הפרטיות שלך, מוגנת"
- Include the app icon (from `apps/mobile/assets/icon.png`) on the left third
- No screenshots inside the feature graphic
- No Google Play badge required

## Placeholder

Create the graphic in Canva, Figma, or Photoshop using the specs above.  
Export as `store-listing/feature-graphic.png` before Play Console upload.

Regenerate app icon if needed:
